## 확정

- `KAKYUSEI.ARC`·`KAKYUHAN.ARC` 형식: 머리 16 B + 20 B 항목. 항목 바이트는 `rol1(b ^ 0xAA)`로 풀고, 이름 14 B + 위치 u32LE(파일 위치 그대로 — 2차에서 바로잡음) + 크기 u16LE. 위치 사슬 어긋남 0 → `tools/ai5arc.py`.
- `.MES` 압축: 비트 스트림 LZSS(MSB 먼저, 표지 1비트, 위치 12 + 길이 4) → `tools/pcmes.py`. 세부값은 2차 참고(1차의 링 0xFEE·길이 +3은 틀렸음).
- MES 이름 609개가 새턴 실행 파일의 MES 이름 610개와 다 겹친다(새턴에만 있는 것은 `FLOOR.MES` 1개). 장면 단위 대응은 이름으로 된다.
- MES 해제본 구조: 머리 + 2바이트 글자표 + AI5 바이트코드(세부는 2차).
  - 본문 글자: 표 글자 / SJIS 선행 −0x20(`0x61~0x7F`, `0xC0~0xCF`) → `tools/pctext.py`.
- 한글 표시: 한글판 `AI5V.EXE` 0x2D9E가 글꼴 칸을 `f = (선행−0x81, 7 이상이면 −3)×189 + (후행−0x40)`로 계산한다. `JISHAN.FNT`(16×16 1비트, 반각 128칸 + 전각)의 전각 칸 **1134부터 KS X 1001 한글 2,350자가 완성형 순서**로 들어 있다(「게」1185·「도」1624로 검산, 그림이 없는 칸도 있다). → `tools/pckr.py`로 한글 문자열 복원.
